I've been using [m0n0dev](http://www.askozia.com/m0n0dev/) for quite some time now to build my m0n0wall-based distro. Over the course of using this tiny script I've made a few patches just to make things work the way I expected; it's far from being perfect anyway. I've already submitted the patch to Michael of [askozia.com](http://askozia.com) the previous week. More functionalities of m0n0dev will be added soon.

**Update: March 5, 2008**

The [patch](http://mindginativelabs.googlecode.com/files/m0n0dev-r14.patch) is now hosted at [Google Code](http://mindginativelabs.googlecode.com).

**Update: March 3, 2008 at 6:32 PM**

A confirmation message from Michael said that my patch had been committed to the main trunk. Instead of applying the patch, you may sync your local copy from the main source tree to get the latest updates.

```text
svn co https://svn.askozia.com:9000/repos/m0n0dev/trunk
```

Enjoy!
