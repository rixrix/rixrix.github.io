As much as I loved [OpenDNS](http://www.opendns.com) because of its fast and reliable DNS servers, its filtering system wasn't working well the previous month. It blocked some legitimate URLs/domains and, to my surprise, my ISP ([PLDT](http://www.pldtdsl.com/)) had partnered with them.

> **If you experience this problem, send SMS to 2331 (Globe/Sun/TM) and 231 (Smart/TNT). Type BB JOSEF or also type BB NIKKI.**

My message to Nikki and Josef:

> Come on, this is **illegal** unless you're blocking those phishing sites — that would be helpful! Blocking domains/sites without **subscribers'** consent isn't right.

**Update: Monday, April 5, 2008**

Even if I dynamically set my DNS server and don't use OpenDNS, it doesn't make sense: my ISP was already using OpenDNS. How did I know? I tried it, and the only difference was that there was no warning message in the browser; the same site simply wouldn't load.
