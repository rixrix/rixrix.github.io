Seventeen days after [Firefox 3 beta 4](http://blog.mozilla.com/blog/2008/03/10/firefox-3-beta-4-out/), out of curiosity I've installed the bleeding-edge Firefox 3 beta 5 pre-release via [Swiftfox's Debian repository](http://getswiftfox.com/deb.htm) into my Xubuntu Gutsy. If [Firefox 3 beta 4 was on a diet](http://arstechnica.com/news.ars/post/20080317-firefox-3-goes-on-a-diet-eats-less-memory-than-ie-and-opera.html) with [memory usage](http://blog.pavlov.net/2008/03/11/firefox-3-memory-usage/), how much more is in the latest incremental release? What do you think?

Swiftfox instructions:

**Add the repository to `/etc/apt/sources.list`:**

```text
deb http://getswiftfox.com/builds/debian unstable non-free
```

**Install from a terminal window as root using the correct package name:**

```text
apt-get update && apt-get install swiftfox-athlon-xp
```
