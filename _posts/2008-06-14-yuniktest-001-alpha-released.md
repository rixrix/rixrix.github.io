Version **0.0.1-alpha** of [yunikTest](http://code.google.com/p/yuniktest/).

> **yunikTest** is a language-agnostic unit testing framework for agile development. It allows one to write tests in different languages and the framework takes care of running the test files. The framework follows some of the TAP protocol formats popularized by Perl Test modules.
